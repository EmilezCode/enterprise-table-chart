# 企业表图

当前版本：2.0.0，原生远程 HTTP 直连。适用 Windows、Codex CLI 和支持 MCP Apps 的 Codex 桌面客户端；不需要 Python 或本地中继进程。

Codex 直接连接本人已经配置的统一企业 MCP。查询、业务规则、表格、图表页面、分析回传和报告下载都由服务端提供。本机只安装固定远程连接配置，没有查询代码或页面副本。服务可以运行在维护者电脑；同事必须能访问该服务，维护者电脑须保持开机、联网、服务运行。GitHub 仅分发首次安装文件。

## 同事安装

将 [INSTALL-PROMPT.md](INSTALL-PROMPT.md) 的整段文字发给同事。公开安装仓库为 https://github.com/EmilezCode/enterprise-table-chart ，只安装一次。

公开仓库正常下载不需要 GitHub 账号或仓库邀请。安装前提：本人已获批并配置启用的 HTTPS `enterprise_data_remote`（当前安装器复用 `http_headers`）；Git 和 Codex CLI 可用。安装不会创建数据账户或扩大权限。纯 OAuth 配置迁移需要单独设置，不能借用他人密钥。

执行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1`。安装器用 `codex mcp get` 在内存中读取本人既有连接，在本人 LocalAppData 下生成远程插件配置，再安装插件并启用 MCP Apps。个人服务地址和授权头只写到本人本机配置及 Codex 插件缓存，不写入源码仓库、不上传 GitHub、不输出到安装日志。不要分享生成后的本机目录。

仓库中的 `.mcp.json` 使用 `example.invalid` 占位，不能直接把公开源码目录当成可用连接。必须通过安装器从本人已有授权生成本机连接。

从1.x升级需执行一次本安装器并重新加载插件/新开聊天。安装器会关闭已知旧本机入口 `edp-render-proof@edp-ui-proof-local`，保留旧 Python 环境和历史卡片；其他旧市场入口按实际安装情况在插件管理中关闭，避免重复。既有企业 MCP 配置、模型、记忆与其他插件保持。

## 日常更新

| 更新位置 | 同事动作 |
|---|---|
| 统一 MCP 上的兼容查询逻辑或表图页面 | 下次查询或重新打开卡片获取新版，无需重装；已打开卡片不会强刷 |
| 固定地址和现有合同下的后续查询、图表、报告功能 | 由维护者更新服务端，同事不需要拉仓库或更新插件 |
| 服务地址、认证方式或不兼容的连接合同迁移 | 按明确迁移说明重新配置；不属于普通功能更新 |
| 个人数据授权 | 由管理员按本人身份调整，必要时本人重新授权 |

没有安装自动轮询、计划任务或后台更新器。`Update.ps1` 仅用于1.x到2.0等明确客户端迁移，普通服务端功能更新不运行它；它只做快进拉取，遇到本地修改停止并保留文件。已经打开的卡片保留当前页面，重新打开卡片获取最新页面。

## 报告下载

报告 Markdown、明细 CSV、摘要 CSV 由当前用户当前结果卡签发短时一次性 HTTPS 下载地址，经宿主打开并由浏览器保存到用户电脑。授权仍在服务端检查；下载地址不携带长期访问 Token，不要转发短时下载链接。浏览器按自己的下载设置保存；“已发起下载”不等于已经落盘。复制报告、分析回原卡和换题流程保持。

## 维护者

所有发布文件均可直接检查。不要提交 config.toml、Token、.env、业务结果或运行截图。日常服务发布走现有服务维护流程，本仓库安装不会部署或重启服务。修改客户端代码时提升插件版本，再发布新版本。文档变更不要求重装插件。

公开范围为本仓库的安装脚本、占位配置、安装说明及 Git 提交历史；旧版本中继代码仍保留在历史中。不包含企业 MCP 服务地址、访问凭据、业务查询结果、数据库或服务端业务实现。下载插件不授予企业数据访问权限。

本机已完成原生 HTTP 安装、本人授权下的真实服务连接、实际表图显示、分析回原卡，以及含分析的 MD 报告、CSV 明细、CSV 摘要的浏览器下载落盘检查。另一台同事电脑的网络、授权和实际侧栏仍需该设备确认。本机检查记录仅保留任务 evidence，不上传业务结果或运行日志。
