# 企业表图

适用 Windows、Codex CLI、支持 MCP Apps 的 Codex 桌面客户端、Python 3.11+。

插件仅提供个人授权连接和本机报告下载。查询、业务规则、表格和图表页面由本人已经配置的统一企业 MCP 服务提供。服务可以运行在维护者电脑；同事必须能访问该服务，维护者电脑须保持开机、联网、服务运行。仓库不是数据服务器。

## 同事安装

将 [INSTALL-PROMPT.md](INSTALL-PROMPT.md) 的整段文字发给同事，先选一个其有权读取的私有仓库。两个仓库是相同发行内容的镜像，只选一个安装。

安装前提：同事自己登录 GitHub 并获仓库读取权限；本人已获批并配置 HTTPS `enterprise_data_remote`（当前中继支持 `http_headers`）；Codex CLI 与 Python 3.11+ 可用。安装不会创建数据账户或扩大权限。纯 OAuth 配置目前不支持，不能借用他人密钥。安装依赖需要访问 Python 包源。

安装器创建用户 LocalAppData 下的独立 Python 环境，登记插件仓库、安装插件并启用 MCP Apps。它不会修改既有企业 MCP 配置、模型或记忆。已有旧版插件时，先在插件管理中关闭旧版入口，避免重复；不要卸载其他插件。

## 日常更新

| 更新位置 | 同事动作 |
|---|---|
| 统一 MCP 上的兼容查询逻辑或表图页面 | 下次查询或重新打开卡片获取新版，无需重装；已打开卡片不会强刷 |
| 本仓库的中继、启动器、依赖或配置 | 在本地仓库执行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\Update.ps1`，然后新开聊天或重新加载插件 |
| 个人数据授权 | 由管理员按本人身份调整，必要时本人重新授权 |

没有安装自动轮询、计划任务或后台更新器；不承诺客户端文件自动热更新。两个镜像由维护者同步推送。`Update.ps1` 只做快进拉取，遇到本地修改停止并保留文件。

## 维护者

所有发布文件均可直接检查。不要提交 config.toml、Token、.env、业务结果或运行截图。日常服务发布走现有服务维护流程，本仓库安装不会部署或重启服务。修改客户端代码时提升插件版本，再将同一提交推送到两个镜像。

本轮安装器与 stdio 连接检查记录见本机任务 evidence；另一台同事电脑安装、网络可达与实际侧栏界面仍需同事端确认。

官方机制：[插件打包与私有仓库分发](https://developers.openai.com/plugins/build/plugins)。
